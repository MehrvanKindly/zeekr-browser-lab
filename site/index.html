READ THE RESULT CORRECTLY

Investigation targets.
Not findings about your car.

This lab does not identify the EU 7X’s browser implementation. A WebView-looking user agent can be changed or reduced; it does not verify the app’s engine, build, configuration or Android security patch level.

Android’s documented risk classes include exposed native bridges, unsafe URI handling and permissive file access. Engine memory-safety bugs require an applicable vulnerable build. Testing their exploitability needs a controlled lab and a verified vendor build.

There is no standard webpage command to enable ADB, silently install an APK or root a vehicle. This lab does not attempt those operations, vehicle control, native method invocation, permission prompts or automatic app launches.
